# Landing — page overrides

> Overrides `MASTER.md` for the public marketing site. In-app Loop Session UI uses `loop-session.md`.

**Project:** SpecResearch Loop
**Page:** Landing

---

## Pattern (overrides Master Portfolio Grid)

Verified matches: **Hero + Features + CTA** (SaaS retry) and **Interactive Product Demo** (Productivity Tool).

**Section order:**
1. Hero — headline that a vague idea becomes a verified Research Spec; sticky primary CTA
2. Value prop — human-in-the-loop, not autopilot
3. Five stages as a 3–5 feature row (grilling, related work, claims/evidence, experiment planning, independent judges)
4. Interactive product demo — Loop Session walkthrough, not a masonry gallery
5. Honesty block — readiness criteria, not conference acceptance
6. CTA + footer

**CTA copy:** Start a Loop Session / Continue. Gold accent fill. Secondary: navy outline.

Hero scroll-reveal (Master motion 3/10) is allowed here; skip under `prefers-reduced-motion`. Disable parallax.

---

## Typography

Landing may use **EB Garamond** (vietnamese subset) for the hero headline and honesty-block pull quote. Body and UI controls use **Be Vietnam Pro** (same as Loop Session) so the demo embeds match the product.

---

## Anti-patterns

- ❌ Visuals-first portfolio grid / “filter by publication”
- ❌ Dark mode by default; excessive animation (SaaS anti-pattern)
- ❌ Glassmorphism hero panels
- ❌ Copy that promises paper acceptance or “agent swarm” research
